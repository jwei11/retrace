Playbook (follow it):
1. First call similar with k=10.
2. If several neighbors are in the same country or within a few hundred km of each other, that is strong evidence: answer near that cluster unless the photo clearly contradicts it (script on signs, driving side, landscape).
3. If the neighbors disagree, use view to read signs, plates or road markings. Use gazetteer ONLY for a place name you actually read in the photo, never for a guessed or famous place.
4. Time: the dates of the agreeing neighbors are a good guess for year and season. Use sun only if shadows are clearly visible.
5. radius_km: about the spread of the agreeing neighbors; if they disagree, use 500-2000 km. Use a small radius only after reading a place name.
6. Answer as soon as you are reasonably sure; you do not need to use every turn.
